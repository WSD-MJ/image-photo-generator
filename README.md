# Corporate Portrait Generator — Agent Skill

An AI Agent Skill that turns a personal photo into a polished, professional **corporate portrait / business headshot** — selectable backgrounds and outfits, no influencer glamour, just a clean reliable professional look.

Works with Claude Code, Cursor, Codex, OpenClaw and any agent that supports the open `SKILL.md` standard.

## What it does

Upload a selfie (URL or base64) and choose a style; it returns a business-grade portrait — ideal for LinkedIn, company websites, and uniform team headshots.

## Install / use

Install with the [skills CLI](https://www.skills.sh/docs/cli):

```bash
npx skills add WSD-MJ/image-photo-generator
```

The skill lives in [`corporate-portrait-generator/SKILL.md`](./corporate-portrait-generator/SKILL.md).

1. Get an API key at https://ai.wsdsocial.com/skills
2. Set `WSD_API_KEY` as an environment variable
3. See the SKILL.md for the request format
